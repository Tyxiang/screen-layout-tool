# 布局文件

## 1. 文件

- 布局使用 JSON 格式，一个文件定义一个布局。
- 文件名作为布局名称。
- 布局包含作者、版本、描述和位置列表。
- 位置列表的顺序决定窗口位置的切换顺序。

## 2. 字段

### 2.1. 布局

| 字段          | 类型   | 说明                       |
| ------------- | ------ | -------------------------- |
| `author`      | 字符串 | 作者                       |
| `version`     | 字符串 | 布局版本                   |
| `description` | 字符串 | 布局描述                   |
| `positions`   | 数组   | 位置列表，至少包含一个位置 |

### 2.2. 位置

位置和尺寸以显示器工作区域为基准，单位为百分比，支持小数。

| 字段      | 类型 | 说明                                    |
| --------- | ---- | --------------------------------------- |
| `x`       | 数值 | 窗口左边缘距工作区域左边缘的距离        |
| `y`       | 数值 | 窗口上边缘距工作区域上边缘的距离        |
| `left`    | 数值 | 窗口左边缘距工作区域左边缘的距离        |
| `right`   | 数值 | 窗口右边缘距工作区域右边缘的距离        |
| `top`     | 数值 | 窗口上边缘距工作区域上边缘的距离        |
| `bottom`  | 数值 | 窗口下边缘距工作区域下边缘的距离        |
| `width`   | 数值 | 窗口宽度                                |
| `height`  | 数值 | 窗口高度                                |

## 3. 位置描述

每个位置需要确定水平位置、垂直位置、宽度和高度。

水平位置和宽度可使用以下任一组合：

- `x` 和 `width`
- `left` 和 `width`
- `right` 和 `width`
- `left` 和 `right`
- `x` 和 `right`

垂直位置和高度可使用以下任一组合：

- `y` 和 `height`
- `top` 和 `height`
- `bottom` 和 `height`
- `top` 和 `bottom`
- `y` 和 `bottom`

可以同时填写多个字段。程序按以下顺序确定位置和尺寸：

- 水平位置：优先使用 `x`；其次由 `right` 和 `width` 计算；最后使用 `left`。
- 垂直位置：优先使用 `y`；其次由 `bottom` 和 `height` 计算；最后使用 `top`。
- 宽度：优先使用 `width`；其次由 `left` 和 `right` 计算；最后由 `x` 和 `right` 计算。
- 高度：优先使用 `height`；其次由 `top` 和 `bottom` 计算；最后由 `y` 和 `bottom` 计算。

位置和尺寸按以下规则处理：

- 字段值小于 0 时按 0 处理，大于 100 时按 100 处理。
- 字段之间不一致时，按上述顺序确定结果，不因不一致报错。
- 计算出的窗口矩形超出工作区域时，取窗口矩形与工作区域的交集作为最终位置和尺寸。
- 修正后的宽度或高度小于或等于 0 时，报告错误。
- 不修改布局文件中的原始值。
- 位置修正后，如果存在重复位置，报告错误，不使用该布局。

## 4. 示例

```json
{
  "author": "Tyx",
  "version": "1.0",
  "description": "两个窗口位置",
  "positions": [
    {
      "left": 0,
      "width": 50,
      "top": 0,
      "height": 100
    },
    {
      "right": 0,
      "width": 50,
      "top": 0,
      "bottom": 0
    }
  ]
}
```
