# 设计

## 1. 概述

Screen Layout Tool 是 Windows 窗口布局工具。用户选择布局后，可通过快捷键将当前窗口切换到布局中的位置。

## 2. 技术栈

- 开发语言：Go，关闭 CGO。
- Windows API：`golang.org/x/sys/windows`。
- 托盘菜单和通知：通过 Windows API 实现。
- 全局键盘和鼠标快捷键：通过 Windows 低级键盘、鼠标钩子实现。
- 显示器和窗口操作：通过 Windows API 实现。
- 自动启动快捷方式：`github.com/go-ole/go-ole`。
- 用户设置读写：`gopkg.in/ini.v1`。
- 布局文件解析：标准库 `encoding/json`。
- 日志：标准库 `log/slog`。
- 内置资源：标准库 `embed`。
- 连续操作计时：标准库 `time`。
- 消息循环线程绑定：标准库 `runtime`。
- 测试：标准库 `testing`。

## 3. 系统组成

### 3.1. 程序

- 单个可执行文件。
- 在系统托盘提供菜单，接收菜单操作。
- 注册快捷键，接收布局和窗口位置切换操作。
- 管理当前布局和自动启动设置。
- 管理自动启动快捷方式。
- 获取显示器和当前窗口的信息。
- 移动窗口、调整窗口边缘和尺寸。
- 读取布局，将窗口移动到指定位置或最接近的位置。
- 按布局的位置顺序切换窗口位置。
- 根据操作结果提示错误。

### 3.2. 托盘图标和菜单

托盘图标：

- 托盘图标使用项目图标。
- 鼠标指针悬停在托盘图标时提示 `Screen Layout Tool`。
- 右键点击托盘图标打开托盘菜单。

托盘菜单组成、顺序：

```text
Layout              >
  布局名称
  布局名称
Open Layout Folder
---------
Auto Start
---------
About
Help
---------
Reload
Exit
```

托盘菜单样式、内容：

- 菜单使用 Windows 原生样式，字体、颜色和间距使用系统默认值。
- 布局名称保持文件名，不含扩展名。
- 当前布局显示勾选。
- 布局子菜单按布局文件名排序。
- 没有布局时，布局子菜单显示禁用的 `No Layouts Available`。
- 自动启动开启时，`Auto Start` 显示勾选。

托盘菜单功能：

- 点击布局名称时，将其设为当前布局，保存设置并更新菜单勾选。
- 点击 `Open Layout Folder` 时，使用资源管理器打开布局目录；目录不存在时先创建。
- 点击 `Auto Start` 时，切换自动启动状态，保存设置、更新启动快捷方式和菜单勾选。
- 点击 `About` 时，显示包含程序名称和版本号的消息框。
- 点击 `Help` 时，使用默认浏览器打开 `https://github.com/Tyxiang/screen-layout-tool#readme`。
- 点击 `Reload` 时，取消尚未执行的快捷键操作，重新读取设置和布局列表，更新托盘菜单。
- 点击 `Exit` 时，取消尚未执行的快捷键操作，注销键鼠钩子，移除托盘图标并退出程序。

### 3.3. 布局文件

- 布局负责定义可用位置。
- 布局以 JSON 文件保存在程序所在目录的 `layouts/` 中。
- 发布包中提供默认布局 `Basic`。
- 布局文件名用于在程序中识别布局。
- 布局包含作者、版本、描述和有序位置列表。
- 位置使用显示器工作区域的百分比描述窗口的位置和尺寸。
- 布局文件格式见《布局文件》。

### 3.4. 用户设置

- 用户设置文件名为 `config.ini`。
- 优先使用程序所在目录；该目录不可读写时，使用 `%AppData%\screen-layout-tool\`。
- 选定目录中没有设置文件时，使用默认设置，并在保存时创建文件。
- 两处目录都不可读写时，使用默认设置运行，并提示设置无法保存。
- 运行期间使用同一位置；保存失败时提示用户，不切换位置。
- 默认布局为 `Basic`，默认关闭自动启动。

## 4. 工作流程

### 4.1. 启动

1. 程序被运行。
2. 程序确定用户设置文件的位置，读取用户设置。
3. 程序建立托盘菜单，注册快捷键。
4. 程序读取所有可用布局的文件名，生成布局菜单。
5. 程序根据自动启动设置，更新 Windows 启动文件夹中的快捷方式。

### 4.2. 选择布局

1. 用户在托盘菜单中选择布局。
2. 程序保存当前布局，更新托盘菜单。

### 4.3. 切换窗口位置

1. 用户激活需要调整的窗口。
2. 用户按下 `Win` + 鼠标滚轮 或 `Win` + `←` / `→` 。
3. 程序读取当前布局文件。
4. 程序确定当前显示器。
5. 程序确定目标位置。
6. 程序将当前窗口调整到目标位置。

### 4.4. 管理布局

1. 用户从托盘菜单打开布局目录。
2. 用户用文本编辑器添加或修改布局文件。
3. 用户点击托盘菜单中的 `Reload` 更新布局列表。

### 4.5. 调整设置

1. 用户通过托盘菜单切换自动启动设置。
2. 程序保存设置，更新托盘菜单。
3. 自动启动设置改变时，程序更新 Windows 启动文件夹中的快捷方式。

### 4.6. 退出

1. 用户点击托盘菜单中的 `Exit`。
2. 程序退出。

## 5. 切换规则

### 5.1. 确定当前布局

- 布局列表按布局文件名排序。
- 使用快捷键切换布局时，到达列表的第一项或最后一项后，继续向列表外切换时保持当前布局。
- 快速连续切换布局时，按累计步数切换；方向相反的步数相互抵消，累计步数为 `0` 时保持当前布局。
- 当前布局不存在时，选择布局列表中的第一个布局。
- 没有布局时，程序继续运行并提示用户；用户添加布局文件并重新加载后可以使用。

### 5.2. 确定当前显示器

- 以当前窗口的中心点确定窗口所在的显示器。
- 窗口中心点不在任何显示器内时，选择距离中心点最近的显示器。
- 显示器与窗口中心点的距离，按中心点到显示器边界的最短距离计算。
- 多个显示器距离相同时，优先选择主显示器；其中没有主显示器时，选择编号较小的显示器。

### 5.3. 确定目标位置

- 当前窗口不在布局位置时，选择当前显示器中最接近的位置。
- 分别计算窗口与布局位置的横坐标、纵坐标、宽度和高度的百分比差值，四项差值的绝对值之和最小的位置为最接近的位置。
- 多个位置同样接近时，选择位置列表中最先出现的位置。
- 最接近位置的四项差值绝对值之和小于 `0.5` 时，认为当前窗口已处于该布局位置。
- 当前窗口已在布局位置时，按位置列表顺序选择下一个或上一个位置。
- 到达位置列表的第一项或最后一项后，继续向列表外切换时保持当前位置。
- 快速连续操作时，按累计步数切换；超出列表边界时停在第一项或最后一项。
- 当前窗口不在布局位置时，快速连续操作仍只将窗口移到最接近的位置。
- 快速连续操作中，方向相反的步数相互抵消；累计步数为 `0` 时，不移动窗口。
- 当前窗口最大化时，先恢复为普通窗口，再按恢复后的窗口位置和尺寸确定目标位置。

### 5.4. 连续操作

- 布局切换和窗口位置切换分别累计步数。
- 同类快捷键连续 `200` 毫秒没有新输入时，执行累计操作。
- 窗口位置切换累计期间，目标窗口或当前布局改变时，取消尚未执行的窗口位置切换。

## 6. 错误处理和日志

- 切换窗口位置失败时，程序根据错误类型显示英文提示。
- 提示区分布局文件无法读取、布局格式错误、布局位置无效或重复、窗口调整失败。
- 其他错误显示通用提示。
- 程序将运行过程中的错误记录到日志。
- 用户设置文件名为 `log.txt`。
- 优先使用程序所在目录；该目录不可读写时，使用 `%AppData%\screen-layout-tool\`。
